## ① 연구 질문과 근거

알푀게의 4쪽 발표문은 반복 세타 리프트를 통해 정수론에서 중복도의 역할을 구현하는 증명 전략을 설명한다. 발표문의 약 √X는 길이 X인 폰 망골트 합을 다룰 때의 리프트 반복 횟수다. 이를 차트의 이동평균 기간으로 번역할 근거는 없다. 발표문에는 지표로 옮길 수식이 없으며, 이 제안은 Λ(k)를 가중치로 빌려 쓰는 독립적인 금융 가설이다. RH 및 디리클레 L함수에 대한 GRH의 공개 형식 검증 기록은 수학적 명제의 근거다. 이번 제안은 해당 증명의 Lean 코드를 실행하거나 이식할 필요 없이 구현할 수 있다. 앞선 검토에서 첨부 ZIP과 공개 소스의 동일성은 확인되지 않았다. [발표문, Alpöge, 2026](https://alpo.ge/remark.pdf) · [공개 검증 기록, Sutherland, 2026](https://math.mit.edu/~drew/grh/)

RH로부터 누적 가중치 ψ(N) = ΣΛ(k)에 대해 ψ(N) = N + O(√N log²N)이 따른다. 이 정리는 가중치의 누적 분포를 설명한다. 64개 가중치 자체는 RH의 증명 여부와 무관하게 정확히 계산된다. Λ의 평균이 1이므로 F는 SMA의 희소 부분표본에 가깝고, 사전 기대 효과는 0에 가깝다. 금융 가설은 별도로 설정한다. **일중 계절성과 과거 변동성 수준을 통제한 뒤에도, 시차 위치에 따른 과거 변동의 집중도가 추가 정보를 제공하는가?** [Lee·Nosal, Journal of Number Theory, 2026](https://doi.org/10.1016/j.jnt.2025.12.003)

## ③ 필터 수식과 참조 코드

k = pᵃ이고 p가 소수, a ≥ 1이면 Λ(k) = ln p이며 나머지는 0이다. 시차는 j = k−1로 둔다. w[j] = Λ(j+1)/ψ(64), j = 0,…,63이다.

- F[t] = Σ w[j]·x[t−j]
- S[t] = 최근 64개 x의 단순평균
- D[t] = F[t] − S[t]
- **D̃[t] = D[t] / S[t]** (모델 입력). S[t] = 0이면 결측이다.

D̃는 x의 척도를 바꿔도 값이 같다. 따라서 변동성이 큰 국면이라는 사실만으로 D̃의 크기가 커지지 않는다.

다음 코드는 결측 없이 이어진 단일 구간에 적용하는 참조 구현이다. 저장소의 `mangoldt/` 모듈은 같은 수식에 구간 분리와 입력 검사를 더한 것이며, 함수 이름과 반환 형태가 조금 다르다. 가중치는 현재→과거 순이며 pandas의 창은 과거→현재 순으로 들어온다. 첫 유효값은 종가 65개가 쌓인 시점에 나온다.

```python
import math
import numpy as np
import pandas as pd

def mangoldt_raw(n=64):
    if n < 2:
        raise ValueError("n must be at least 2")
    raw = np.zeros(n)
    for p in range(2, n + 1):
        if any(p % d == 0 for d in range(2, math.isqrt(p) + 1)):
            continue
        k = p
        while k <= n:
            raw[k - 1] = math.log(p)
            k *= p
    return raw

def mangoldt_weights(n=64):
    raw = mangoldt_raw(n)
    return raw / raw.sum()

def wheel_weights(n=64):
    raw = mangoldt_raw(n)
    for k in range(5, n + 1):
        if math.gcd(k, 6) == 1:
            raw[k - 1] = math.log(k)
    return raw / raw.sum()

def control_kernels(w, count, seed, period=None, tol=0.5):
    rng = np.random.default_rng(seed)
    lag = np.arange(len(w))
    groups = [lag[1:]] if period is None else [
        lag[(lag % period == r) & (lag > 0)] for r in range(period)]
    target, found = lag @ w, {}
    while len(found) < count:
        k = w.copy()
        for g in groups:
            k[g] = rng.permutation(w[g])
        if abs(lag @ k - target) <= tol and not np.allclose(k, w):
            found.setdefault(k.tobytes(), k)
    return list(found.values())

def kernel_feature(close, w):
    x = np.log(close).diff().abs()
    n = len(w)
    window = x.rolling(n, min_periods=n)
    weighted = window.apply(lambda values: values @ w[::-1], raw=True)
    simple = window.mean()
    return ((weighted - simple) / simple.where(simple > 0)).rename("d_rel")

def baseline_extras(close):
    r2 = np.log(close).diff() ** 2
    out = pd.DataFrame({"rv1": r2,
                        "rv6": r2.rolling(6, min_periods=6).mean(),
                        "rv42": r2.rolling(42, min_periods=42).mean()})
    out["slot"] = close.index.hour // 4
    return out
```

`control_kernels(w, 200, seed)`는 대조군 C를, `control_kernels(w, 200, seed, period=6)`은 C′를 만든다. 두 경우 모두 w[0]=0, 양수 가중치 27개, Σw²가 원 커널과 같다.

| 64봉 설계 검산 | SMA | 폰 망골트 | 바퀴(W) |
|---|---:|---:|---:|
| 0보다 큰 가중치 수 | 64 | 27 | 29 |
| 가중평균 시차 Σ j·w[j] | 31.50봉 | 32.01봉 | 33.55봉 |
| 유효 표본 수 1/Σ w[j]² | 64.00 | 20.85 | 23.04 |
| 독립·등분산 백색잡음의 출력 분산 / 입력 분산 | 1.56% | 4.80% | 4.34% |

가중평균 시차는 커널의 무게중심이다. 실제 시장 전환을 항상 32봉 뒤에 감지한다는 뜻으로 해석할 수 없다. 현재 봉은 w[0]=0이어서 F에는 다음 봉부터 반영되지만, D에는 현재 봉부터 −1/64의 계수로 반영된다. 따라서 큰 최신 변동 하나가 D를 음수로 만들 수 있다.

### 커널의 24시간 주기 구조

3보다 큰 소수는 6으로 나눈 나머지가 1 또는 5다. 시차 j = k−1에서는 j ≡ 0, 4 (mod 6)에 해당하고, 4시간봉의 6봉은 24시간이다.

| 시차 j mod 6 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| 폰 망골트 가중치 비중 | 41.6% | 3.3% | 5.3% | 3.3% | 46.4% | 0% |
| SMA 비중 | 17.2% | 17.2% | 17.2% | 17.2% | 15.6% | 15.6% |

- F는 가중치의 88.0%를 하루 6개 시간대 중 2개에 싣는다. 어느 2개인지는 현재 봉의 슬롯에 따라 돈다.
- 백색잡음 입력에서 D의 자기상관은 시차 6에서 +0.64, 시차 1에서 −0.41이다.
- 6 이하의 소수를 제외한 6과 서로소인 위치는 64 안에 20개이고, 그중 18개가 소수 거듭제곱이다(예외는 35와 55). **64봉에서는 소수 배열과 "6과 서로소" 배열이 거의 같다.**

이 구조 때문에 D̃는 일중 변동성 계절성에 반응한다. 기준선의 슬롯 특징과 대조군 C′·W는 이 경로를 분리하기 위한 장치다.

## ④ 비교 실험과 코드 구성

모든 모델은 같은 기준 특징 집합 M0을 공유하고, 군마다 특징 한 열만 다르다.

**M0 기준 특징.** ATR(14)/종가, 종가/VIDYA−1, 현재 거래량/20봉 평균, slot(6범주), rv1 = r[t]², rv6 = 최근 6봉 r²의 평균, rv42 = 최근 42봉 r²의 평균.

| 실험 | 모델 입력 | 검증 질문 |
|---|---|---|
| M0 기준선 | 기준 특징 | 계절성과 변동성 군집만으로 얼마나 정확한가? |
| B 제안 모델 | M0 + D̃ | 폰 망골트 특징을 추가하면 개선되는가? |
| C 전역 순열 | M0 + D̃(전역 순열 커널), 200개 | 같은 희소성·가중치 분포만으로 얻을 수 있는 개선인가? |
| C′ 잔여류 보존 순열 | M0 + D̃(잔여류 내 순열 커널), 200개 | 같은 24시간 주기 구조만으로 얻을 수 있는 개선인가? |
| W 바퀴 커널 | M0 + D̃(바퀴 커널), 1개 | 소수 여부를 보지 않는 "6과 서로소" 빗 필터와 다른가? |
| 보조 비교 | M0 + S̃, 그리고 M0 + S̃ + D̃. S̃ = S/√rv42 | 64봉 수준 정보를 따로 준 뒤에도 D̃가 기여하는가? |

**대조 커널 규약.**

- **C.** w[0]=0을 유지하고 나머지 63개 위치에서 가중치 전체를 섞는다. 선택 봉 수, 가중치 분포, 백색잡음 분산이 보존되고 mod 6 구조는 깨진다. 무게중심 ±0.5봉 조건의 통과율은 약 12%다.
- **C′.** 시차 j mod 6이 같은 위치끼리만 가중치를 섞는다. C의 보존 항목에 더해 잔여류별 가중치 비중이 정확히 보존되므로, 순수 주기 입력에 대한 응답이 원 커널과 같다. 무게중심 조건의 통과율은 약 22%다.
- **W.** 2와 3의 거듭제곱에는 Λ를 그대로 두고, 6과 서로소인 k ≥ 5 전부에 ln k를 준다. 소수 판정이 들어가지 않는 결정적 커널이다.
- 마스크 생성 시드와 모델 학습 시드를 따로 기록하고 모든 군에 동일한 학습 시드를 대응시킨다. 마스크는 평가 데이터를 보기 전에 생성해 파일로 고정한다.

**검정력의 한계.** 주요 잔여류 두 개는 각각 10개 위치 중 9개가 이미 양수다. 그래서 C′ 커널은 원 커널과 닮는다. D 커널 기준 코사인 유사도는 C′가 중앙값 0.73(5–95% 구간 0.65–0.83), W가 0.88, C가 중앙값 0.00이다. 2단계 판정은 64봉에서 통과하기 어렵고, 통과하지 못해도 소수 효과가 없다는 증거는 아니다. 사전 등록 민감도 분석으로 128봉 커널을 함께 돌린다. 128봉에서는 6과 서로소인 42개 위치 중 소수 거듭제곱이 33개, W와의 유사도가 0.79로 내려가 구분 여지가 커진다. 128봉 결과는 보조 증거로만 쓰고 1차 판정은 64봉으로 한다.

## ⑤ 검증 절차와 채택 기준

1. **시간 분할.** 기간 순서대로 최초 50%를 초기 학습 구간으로 두고 나머지를 연속된 4개 평가 구간으로 나눈다. 각 구간 직전까지 학습 범위를 확장한다. 라벨 종료 시각이 평가 시작 시각 이상인 학습 행을 제거한다. 과거 64봉을 평가 첫 특징 계산에 쓰는 것은 실시간 관측 조건과 일치한다.
2. **확률 검증.** Brier Score를 주지표로 두고 Log Loss, 10구간 ECE, 사건 발생률, 구간별 표본 수도 기록한다. 기준 확률은 각 학습 구간의 사건 비율이다. 공통 행만 비교하고, Log Loss용 확률 클리핑과 ECE 구간 경계를 모든 모델에 동일하게 적용한다.
3. **불확실성.** ΔBrier(X) = Brier(M0) − Brier(X)로 정의하여 양수가 개선을 뜻하도록 한다. 같은 시각·같은 모델 시드의 손실을 짝지어 비교한다. 시드별 차이를 시각별로 평균한 뒤, 폴드 안에서 연속 블록을 재표집한다. 기본 블록은 42봉(7일), 민감도는 21·84봉으로 한다. 미래 라벨이 겹치는 표본이나 다른 시드를 독립 표본으로 세면 신뢰구간이 과도하게 좁아질 수 있다.
4. **순위 p값.** 대조군 G의 마스크 200개 중 ΔBrier가 B 이상인 개수를 r이라 하면 p(G) = (r+1)/201이다.
5. **사전 채택안 1단계: 특징이 쓸모 있는가.** 다음을 모두 만족하면 다음 검증 단계로 넘긴다.
   - 전체 ΔBrier(B)의 블록 부트스트랩 95% 구간 하한이 0을 넘는다.
   - 4개 평가 구간 중 3개 이상에서 ΔBrier(B) > 0이다.
   - p(C) ≤ 0.05다.
6. **사전 채택안 2단계: 소수 배열 고유의 효과인가.** 1단계를 통과하고 다음을 모두 만족할 때만 "소수 배열"이라는 표현을 쓴다.
   - p(C′) ≤ 0.05다.
   - ΔBrier(B) − ΔBrier(W)의 블록 부트스트랩 95% 구간 하한이 0을 넘는다.
7. **공개 항목.** 판정과 무관하게 최악 구간 ΔBrier, Log Loss 변화, 보정 곡선, 보조 비교, 128봉 민감도, C·C′의 ΔBrier 분포 전체를 공개한다. 문턱값은 실험 제안값이다. 결과를 본 뒤 바꾼 경우 새 기간에서 재검증한다.
8. **구현 수용 검사.**
   - 가중치 합 1, 양수 27개, 잔여류별 비중이 ③의 표와 일치한다.
   - |r|이 일정한 입력에서 D̃=0이고, 단위 충격에서 D의 j번째 응답이 w[j]−1/64다.
   - 종가가 일정한 입력에서 D̃는 결측이다.
   - C·C′ 마스크 각각이 w[0]=0, 양수 27개, 원 커널과 같은 Σw², 무게중심 ±0.5봉을 만족하고 서로 다르다. C′는 잔여류별 비중이 원 커널과 같다.
   - 미래 봉 추가 전후 과거 특징이 같다. 갭 양쪽의 창이 분리된다. 마지막 6봉의 라벨이 결측이다. 모든 군의 평가 시각이 완전히 같다.

같은 64봉 안에서도 일부 봉에 큰 변동이 몰리면 두 평균이 달라진다. D̃>0은 선택된 시차에 큰 절대수익률이 상대적으로 집중됐다는 관찰이다. 상승과 하락 모두 같은 부호로 기여한다.

| 1단계 탈락 | 계절성과 변동성 군집을 통제하면 이 특징의 추가 정보가 확인되지 않는다. |
| 1단계 통과, 2단계 탈락 | 24시간 간격 빗 필터가 슬롯 평균 이상의 정보를 준다. 소수 배열의 고유한 이점은 입증되지 않는다. 지표 이름에서 "소수"를 내세우지 않는다. |

## ⑦ 확장 순서와 한계

- **TradingView 표시.** Python과 동일한 종가·봉 마감 시각에서 Pine v6의 F·S·D̃를 대조한 뒤, 별도 패널에 0선과 D̃를 그린다. 64개 수익률이 확보되기 전에는 결측으로 표시한다. D̃는 슬롯에 따라 평균이 달라질 수 있으므로 화면 해석에는 슬롯별 평균을 뺀 값을 함께 제공한다. 다음 6봉 라벨은 사후 평가에만 쓴다.
- **QQQ 재현.** BTC 설계를 고정한 뒤 별도 외부 표본에서 평가한다. 거래 세션·조정 가격·조기 폐장을 명시하고 6봉의 실제 경과시간을 기록한다. 세션당 4시간봉 수가 6이 아니므로 mod 6 구조의 의미와 C′의 주기 설정이 달라진다. QQQ에서 6봉을 자동으로 24시간으로 해석하면 목표가 달라진다.
- **별도 주기성 연구.** 거래량 급증 뒤 경과 봉 수 τ≥1에 대해 제타 영점의 허수부 γ를 이용한 sin(γ log τ), cos(γ log τ)를 일반 주파수와 비교할 수 있다. 주기가 언제 나타나고 사라지는지가 질문이라면 라마누잔 필터뱅크가 문헌에 근거한 비교 방법이다. 두 연구는 1차 실험과 독립적으로 평가한다. [Tenneti·Vaidyanathan, 라마누잔 필터뱅크 연구](https://authors.library.caltech.edu/records/2jeyx-thq78)
